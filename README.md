AI Applyd is a job-application automation platform for candidates: it scores a resume against a posting for ATS compatibility, rewrites the resume and writes a cover letter per role, prepares interview material, matches new postings to a profile, and fills and submits applications on the employer's own hiring system across 15 ATS platforms (Workday, Greenhouse, Lever, Ashby, Workable, iCIMS, SmartRecruiters and more), counting an application as sent only when the employer's system confirms it. It publishes a hosted remote MCP server at mcp.aiapplyd.com/mcp (OAuth 2.1, 17 tools, listed in the official MCP Registry as com.aiapplyd/aiapplyd) with an MIT-licensed stdio bridge on GitHub, and serves the OpenAPI 3.0 description of its application backend at api.aiapplyd.com/api/v1/openapi.json.

**Areas:** Job Search · Recruiting · Resume · Applicant Tracking Systems · Careers · Artificial Intelligence · MCP · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AI Applyd: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
